# 输出模板与示例

> 以下示例仅示范格式与语气，其中的活动名称、地点为占位符，不是真实活动。实际输出必须全部来自指定日期（yyyymmdd 参数）搜索查证的结果。

## 暖心文字模板（正文 3 个活动）

亲爱的爷爷奶奶，早上好呀～

{X月X日（周X）}我又为您打听了 3 个免费的小惊喜，都在您家附近，走一走就能到：

【惊喜一：活动名称】
内容：……
地点：……
距离：距您约 X 公里，步行约 X 分钟
电话：报名/咨询可打 {电话}（活动有联系电话时必写此条；没有就不写，不编造）

【惊喜二：活动名称】
内容：……
地点：……
距离：……

【惊喜三：活动名称】
内容：……
地点：……
距离：……
电话：报名/咨询可打 {电话}（同上）

贴心提醒：出门记得带好身份证/敬老卡，看好天气增减衣物，路上慢一点，玩得开心最重要！

## 语气要点

- 开头用"惊喜"而非"活动"，制造期待感
- 每段先报名称，再报内容、地点、距离，条理清楚
- 收尾落在家常叮咛上（证件、天气、安全），像晚辈说话
- 若搜索结果中有健康/理财类讲座，加一句"这类活动听听无妨，但涉及付费、买卡、买保健品要多留个心眼"
- 距离全部标注"约"，并注明"距离为估算，请以导航为准"
