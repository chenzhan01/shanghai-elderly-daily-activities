# 上海各区官方媒体与免费活动常发渠道

> 名单供搜索参考；账号/网站名称可能调整，使用前用搜索确认当前名称。

> **记录要求（所有渠道通用）**：本文件列出的任何渠道——市级、各区官方新媒体、区政府网站/文旅局/图书馆/文化馆、街道综合为老服务中心、微博等——抓到活动后，一律按 SKILL.md《活动记录规范（所有渠道通用）》写入 `{当前工作目录}/上海老人活动总表_{YYYY-MM}.md`（按"区 → 日期 → 活动"分组；字段含 时间 / 地点（场所名（区名+路名门牌号））/ 内容 / 对象 / 费用 / 状态（即将开始·进行中·已结束）/ 报名咨询 / 来源；去重键＝活动名称＋活动日期＋地点；已结束条目不删除只标状态；费用原文没写不默认免费；地点只写场所名的须补全门牌号）。活动数据不写入 JSON 缓存，缓存只记当日是否已跑过全量检索。

## 市级渠道

- **在场 ONSITE（每日必搜，第一入口）**：<https://zainow.cn/> ，结构化接口 `https://zainow.cn/api/v1/feed`（一次返回全量 events，字段含 title / category / venue / address / startDate / endDate / priceText / isFree / sourceUrl）；本地筛 `startDate ≤ 目标日 ≤ endDate` 且 `city=上海`，不必逐页翻。只取 `isFree=true` 或原文明确"免费"、且无需预约/报名的条目，其余不收（门槛见 SKILL.md《活动记录规范》）；聚合页标注的免费与预约状态需回到 `sourceUrl` 复核
- 上海发布（市政府新闻办官方新媒体）
- 上海市人民政府官网"便民提示"栏目（www.shanghai.gov.cn/nw17239/，要闻动态下的便民提示，每日更新各区党群服务中心活动预告、文化活动预告、社区服务与就业服务站活动安排等，可直接筛出免费活动）
  - 翻页规则：当天内容常常不止一页。首页（index.html）翻完若仍是当天内容（页面上的日期几乎全是当天），继续看 index_2.html、index_3.html、index_4.html……依次往后翻（无 index_1.html，访问会 404）；直到某一页出现明显是前几天的消息（当天条目已不再是主流），才停止翻页
  - 抓取规则：只抓"便民提示"目录下的内容，不抓同一首页的热点新闻/要闻目录条目。**按标题先筛选，再决定是否点开**：只打开与老人或全体市民"休闲娱乐/可参与"有关的链接（文化展览、演出、评弹戏曲、市集、城市游览、赏花、文体活动、亲子活动、为老服务、敬老活动等）；就业招聘、职业指导、岗位招募、政策解读、价格信息、企业论坛、证书领取、办事通知这类与老人休闲无关的链接**不打开**；标题看不出主题、或看着像活动但不确定是否适合老人的，再点进去判断。每条收录活动抓取：活动名称、内容、地点、时间、费用、联系电话、面向对象、来源 URL

## 免费活动常发渠道（适合老人）

- 区图书馆：免费讲座、展览、读书会、老年电脑/手机课
- 区文化馆/群艺馆：文艺演出、戏曲、合唱、舞蹈、书法培训
- 社区党群服务中心 / 邻里中心 / 街道文体活动中心：便民服务、义诊、手工、观影、棋牌
- 街道综合为老服务中心：手工、健康讲座、节庆（做糕、游园会）、金婚纪念等小型免费活动，几乎各街镇都有、常办常新；规模小、水平一般但免费、就在家门口，适合"有规模活动缺乏的日子"作补充（发布渠道见下节）
- 免费公园：晨练、广场舞、赏花、漫步（留意公园免费开放名单）
- 博物馆/纪念馆：免费开放或免费开放日、老年专场讲解
- 区老年大学 / 老年协会 / 老龄办：课程与活动
- 街镇官方公众号：社区活动预告（如梅陇镇"人文梅陇"、各街镇"XX发布"）

## 街道综合为老服务中心的查询渠道（一般无独立官网）

为老服务中心本身没有独立网站，活动预告通过以下线上渠道发布，搜不到官网时按此查找：

- 区政府网站"社区服务 / 便民公告"栏目：街镇会把为老服务中心月度活动菜单挂在这里（实例：杨浦新江湾城街道"综合为老服务中心十月活动安排"、浦东老港镇"五福"养老活动安排）
- 随申办区级旗舰店：部分区设有"活动日历 / 街镇活动 / 养老专版"板块（实例：静安旗舰店汇聚全区活动日历）
- 区/街镇自有小程序：如金山"卫服务"（可查镇上为老服务中心每周手工、健康讲座）、普陀曹杨"美好生活掌中宝"（活动预约、公益电影）
- 街镇官方公众号与社区微信群：发布为老服务动态与活动预告（实例：普陀宜川路街道）
- 上海社区云微信小程序：居委会发布的为老服务活动报名（全市居村委通用，优先使用）

## 检索技巧

- 关键词示例："今日闵行 免费活动"、"XX街道 党群服务中心 活动"、"XX区文化馆 免费 演出"、"XX 公园 免费 活动"
- 官方活动常以"公益""惠民""敬老""老年专场""市民开放日""免费开放"等词出现
- 发现候选活动后，用 web_fetch 打开原文，确认时间、地点、费用与报名方式后再采用
